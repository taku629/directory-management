# 課金まわりの設計メモ

## 全体の流れ

```
ユーザ           Lemon Squeezy        licenser              Sift App
  │                   │                  │                     │
  │ 購入 (¥4,800)      │                  │                     │
  ├──────────────────>│                  │                     │
  │                   │ webhook          │                     │
  │                   ├─────────────────>│                     │
  │                   │                  │ Ed25519 で署名      │
  │                   │                  │ SIFT-PRO-XXXX 生成  │
  │ メール (キー)      │<─────────────────┤                     │
  │<──────────────────┤                  │                     │
  │                                                            │
  │ 設定画面でキー貼る                                          │
  ├───────────────────────────────────────────────────────────>│
  │                                                            │ verify_license()
  │                                                            │ (公開鍵で署名検証)
  │ Pro 機能解放                                               │
  │<───────────────────────────────────────────────────────────┤
```

## なぜ Lemon Squeezy?

| | LS | Stripe 直 |
|--|--|--|
| 手数料 | 5% + 固定 | 3.6% + 固定 |
| 税金 (世界各国の VAT, 消費税, 米州 sales tax) | LS が処理 | 自分でやる |
| インボイス対応 | LS が出す | 自分でやる |
| ライセンスキー機能 | あり | 別途実装 |
| メール送信 | あり | 別途 |
| 国別価格 | あり | 別途 |
| 法的責任 (Merchant of Record) | LS が引き受け | 自分 |

個人開発で最初に Stripe 直は地獄。LS で始めて、年間売上 1000 万超えてから検討。

## ライセンスキーの 2 段構え

LS は LS フォーマットのキーを発行するけど、Sift は **自前の Ed25519 署名形式** で
受け付ける。これは:

1. ベンダーロックイン回避 (将来 Stripe / Paddle / 自前に乗り換えられる)
2. オフライン検証 (LS の API に毎回行かなくていい)
3. ライセンス漏洩したとき自前で失効リスト持てる

実装の流れ:

1. LS の購入 webhook を Vercel API Route で受ける
2. payload 検証 (LS の HMAC)
3. `licenser` API に `POST /issue` で SIFT-PRO-... トークンを発行してもらう
4. 購入者のメアドにトークン送付 (Resend で OK、月 3000 通まで無料)

## 価格

| | 価格 | 計算根拠 |
|--|------|--------|
| Free | ¥0 | Eagle・Hazel・DaisyDisk の無料デモ枠を意識 |
| Pro 買い切り | ¥4,800 | Hazel ($42 ≒ ¥6,300) より少し安い、Eagle ($30 ≒ ¥4,500) と同等 |
| Pro サブスク | ¥500/月 | 買い切り 10 ヶ月 = ¥5,000 で逆転、サブスク優遇 |
| Team | ¥1,200/ユーザ/月 | Pro より高くないと意味ない、最低 5 シート |

## 試用期間

14 日 Pro 全機能。クレカ不要でいきなり使える。
14 日後は **強制 free 落ち** (壊れない、機能が使えなくなるだけ)。

## アクティベーション制限

Pro 買い切り = 同時 3 デバイスまで。`licenser` の `machine_ids` で管理。
ユーザがどれかをデアクティベートしないと 4 台目はエラー。

## 払い戻し

14 日以内、理由不問で全額。ユーザがメールしてきたら LS の管理画面でぽちっと返金 →
`licenser` の `/revoke` を叩く → ライセンスが死ぬ。

## 不正対策

- 海賊版にしない: 完全にしないのは無理。気にしない。割れる人は最初から買わない
- キー共有対策: 同時アクティベート 3 台で十分。それ以上やる人は商業ライセンスにする
- リバースエンジニアリング対策: しない。Rust バイナリのリバースは時間かかる前提
- DRM: 入れない (UX 損なう)

## 領収書 / インボイス

LS が自動発行 (PDF メール添付)。インボイス番号は LS 側に登録すれば反映される。
日本の場合はインボイス制度対応のために自分の登録番号を LS の Tax settings に入れる。

## アカウント / ログイン

最初は **入れない**。デスクトップアプリにログインを強要すると面倒度が跳ね上がる。
ライセンスキーをメールで配って、それを設定画面に貼るだけ。

クラウド同期 (Phase 4.5) を入れる段階で初めてログインを足す。それまでは
ライセンスキーがアイデンティティ。
