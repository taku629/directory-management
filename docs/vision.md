# これ何作ってるの

個人プロジェクト。ローカルのファイル/フォルダ管理アプリ。

## 動機

自分の Mac/Windows のファイル管理が破綻してる。

- ダウンロードフォルダに 1 万件溜まってる
- iPhone から自動同期される写真がフォルダに無限に増える
- スクリーンショットが Desktop を埋め尽くす
- 「あの PDF どこいったっけ」が日常茶飯事
- タグ付けたいのに OS 純正のタグは使いにくい
- ChatGPT/Claude 使ってると、AI で勝手に分類してくれていいじゃんって思う

Hazel 買ったけど Mac だけだし、Eagle は重いし、結局自分の理想を満たすのは
ないので、自分用に作ることにした。

## 仮の名前

`sift` (ふるい分けるの意)。ピンと来てない。
他の候補: `nest` / `stash` / `drawer` / `perch`

## 自分以外に売る話

「自分が使う」が第一目標。もし他の人にも便利そうなら課金もアリ。

ターゲット (希望的観測):

- 自分と同じくダウンロードフォルダがカオスな人
- 写真めちゃくちゃ撮るけど整理しない人
- 設計資料/PDF を大量に扱うエンジニアやデザイナー
- 「Mac なら Hazel あるけど Windows でも欲しい」勢

## やりたいこと

| | やりたい度 |
|--|--|
| ブラウズ + タグ + 検索 (Phase 1) | ★★★ いま実装中 |
| ルール自動整理 (Phase 2) | ★★★ 一番欲しい機能 |
| 重複検出 (Phase 2) | ★★ あると嬉しい |
| ディスク使用量可視化 (Phase 2) | ★★ DaisyDisk 相当 |
| AI タグ付け / 検索 (Phase 3) | ★★★ 売りになるなら |
| クラウド同期 (Phase 4) | ★ 余裕あれば |

## やらないこと (たぶん)

- スマホアプリ (Web ビューワだけならアリ)
- 共同編集
- Dropbox の代替になること (連携はする、置き換えはしない)
- フル機能のファイル管理ソフト (rsync 的な高度な機能はやらない)

## 使ってみての完成形

休日に届くアレ:

> 起動 → `~/Downloads` 指定 → 30 秒で全インデックス完了 →
> ルール 1 個書く: PDF を Documents/年/月 に → 翌日 Downloads が空に →
> AI 機能を ON にして写真ライブラリ放置 → 翌日タグ付いてる →
> 「先月撮った犬の写真」で検索 → ちゃんと出てくる →
> 友達に教える

ここまで来たら成功。
