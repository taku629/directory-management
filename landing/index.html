FAQ

無料版はずっと無料?

はい。広告も期限もなし。Pro 機能だけ課金。

クラウドにファイルが上がるの?

標準で上がりません。AI 機能を使うときだけ、対象ファイル単体が Anthropic の API に送られます。それ以外は完全ローカル。クラウド同期 (Pro) は明示的にオンにしたときだけ動きます。

API キーは自分のを使うの?

はい。Anthropic console で発行したキーを設定画面に貼ります。中継サーバはありません。コストもユーザ自身負担なので、使った分しかかからない (画像タグ付け 1000 枚 = だいたい ¥750)。

買い切り版のアップデートはどこまで?

購入後 1 年間 (= 同じメジャーバージョン内) のアップデート全部。それ以降は使い続けられますが、新しいメジャーバージョンには移れません。50% オフで再購入できます。

返金は?

購入から 14 日以内、理由不問。hello@sift.app まで。

Mac App Store / Microsoft Store にある?

今は直販のみ。サンドボックス制限でルール監視機能が制限されるためです。将来出すかも。

オープンソース?

ソースは公開していますが、ライセンスは商用 (個人利用・非商用なら自由)。詳細は LICENSE。
