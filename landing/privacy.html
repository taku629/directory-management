プライバシーポリシー

最終更新日: 2026-05-05

Sift (以下「本サービス」) を提供する taku629 (以下「当方」) は、本ポリシーに従い個人情報を取り扱います。

1. 収集する情報

1.1 アプリがローカルに保存するもの

  • ファイルのメタデータ (名前、パス、サイズ、更新日時、ハッシュ、タグ、評価、メモ)
  • ライセンスキーと有効化日時
  • API キー (ユーザが入力した場合)
  • 機械固有 ID

これらは ユーザのコンピュータの中だけ に保存され、当方のサーバには送信されません。

1.2 当方のサーバに送られるもの

  • ライセンス検証: 有効化時にライセンスキーと匿名化された機械 ID
  • 自動アップデート: 更新確認時にアプリのバージョンと OS
  • 使用状況テレメトリ (オプトイン、デフォルトオフ): 匿名化された機械ハッシュ、アプリのバージョン、OS、ロケール、機能利用カウンタ

1.3 サードパーティに送られるもの

  • Anthropic (Claude API): AI 機能を使ったとき、対象ファイル単体 (画像/テキスト) と関連プロンプトのみ。ユーザの API キーで直接通信し、当方は中継しません。
  • クラウド同期 (オプトイン、Pro): ユーザが選択したクラウドプロバイダ (S3/Dropbox 等) に、ユーザのファイル/メタデータが直接アップロードされます。当方は中継しません。
  • 決済 (Lemon Squeezy / Stripe): 購入時のメールアドレス、請求情報。各社のプライバシーポリシーに従います。

2. 絶対に送らないもの

  • ファイルの内容
  • ファイル名、パス、ディレクトリ構造
  • タグ、メモ、評価
  • API キー、ライセンスキー本体
  • 個人を特定できる情報 (テレメトリは匿名)

3. クッキー

本デスクトップアプリ自体はクッキーを使いません。マーケサイト (sift.app) は分析用に最小限使う場合があります。

4. 第三者提供

法令に基づく場合を除き、第三者には提供しません。

5. データの削除

アプリをアンインストールすればローカルデータは消えます。ライセンス情報の削除は hello@sift.app まで。

6. 改定

本ポリシーは予告なく改定する場合があります。重要な変更は本ページで告知します。

7. お問い合わせ

hello@sift.app

本ポリシーはテンプレートです。実際の公開前に弁護士にレビューしてもらうことを推奨します。
